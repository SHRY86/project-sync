WHAT IS ACTUALLY P2P?

Each Web Worker independently selects dancing, note/vowel, spotlight intensity and show section. Workers exchange timed state directly using BroadcastChannel.

Not P2P: the shared display, speaker and the one-time initial start cue. On real computers, synchronized audio playback needs a distributed clock solution.

Pure JavaScript + Three.js · Separate agent workers · No backend or logins · Synthetic vowel vocals (not lyric synthesis)
